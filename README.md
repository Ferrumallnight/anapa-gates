# Песчаный — Калитки

Готовое статическое PWA для `https://Ferrumallnight.github.io/anapa-gates/`. Сборка, Node.js, API-ключи и сервер приложения не нужны.

## Публикация через сайт GitHub

1. Войдите в аккаунт **Ferrumallnight**. Создайте публичный репозиторий **anapa-gates** (если он уже существует, откройте его).
2. Распакуйте архив. Откройте папку `anapa-gates`.
3. В репозитории выберите **Add file → Upload files**. Загрузите **содержимое** папки: `index.html`, `styles.css`, `app.js`, `gates.js`, `sw.js`, `manifest.webmanifest`, папку `assets` и остальные файлы. `index.html` должен лежать в корне репозитория, не в ещё одной папке `anapa-gates`.
4. Нажмите **Commit changes**, сохранив файлы в ветке `main`. Скрытый файл `.nojekyll` тоже включён в архив; при необходимости создайте его через **Add file → Create new file**.
5. Откройте **Settings → Pages**. В **Build and deployment → Source** выберите **Deploy from a branch**. Укажите **main**, **/(root)** и нажмите **Save**.
6. Дождитесь завершения публикации в разделе **Actions** и откройте **https://Ferrumallnight.github.io/anapa-gates/**.

[Официальная инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

Вложенная база `/anapa-gates/` уже учтена в manifest. Ссылки на файлы и service worker относительные. Service worker ограничен папкой приложения и не обслуживает другие проекты аккаунта. При переименовании репозитория измените `id`, `start_url`, `scope` в manifest.

## Использование

Нажмите на маркер или выберите калитку в списке. Масштаб — двумя пальцами, колесом мыши или кнопками +/−; перемещение — перетаскиванием. Кнопка ⌖ показывает весь генплан. С клавиатуры: Tab до карты, +/−, стрелки, 0 для сброса.

На iPhone откройте сайт в Safari → «Поделиться» → «На экран Домой». На Android — команда установки в меню браузера или кнопка «На главный экран» в приложении.

Телефоны сверены с подписями пользователя: №1 — **+79604989329**, №2 — **+79604957663**, №3 — **+79604989331**, №4 — **+79604989344**, №5 — **+79604989345**, №6 — **+79604989466**. Все шесть кнопок звонка доступны. Приложение использует прямые ссылки `tel:`; iOS самостоятельно запрашивает подтверждение звонка, приложение его не обходит. [Документация Apple](https://developer.apple.com/library/archive/featuredarticles/iPhoneURLScheme_Reference/PhoneLinks/PhoneLinks.html).

Для открытия требуется, чтобы система калитки принимала звонки с вашего номера. Успех открытия приложение не определяет. Офлайн работает интерфейс и карта после первой успешной загрузки; звонку нужна мобильная связь.

## Как менять калитки

Все данные находятся в **gates.js**:

- `id`: постоянный внутренний идентификатор, оставляйте уникальным.
- `number`: отображаемый номер калитки.
- `x`, `y`: проценты от левого верхнего угла карты (0–100). Дорога внизу. Пример: `x: 50, y: 50` — центр.
- `phone`: номер вида `'+79604957663'` или `null`, чтобы отключить звонок.
- `photo`: путь вида `'./assets/gate-2.jpg'` или `null`.
- `description`: подпись в карточке.

Нумерация и положения перенесены с новой пользовательской схемы `reference/gates-perspective-annotated.jpg`. Нумерация подтверждена пользователем после обхода территории. Фон — предоставленный пользователем `план.jpg`, сохранённый без изменений как `assets/masterplan-perspective.jpg`. Он показан без поворота и обрезки. Кликабельные маркеры перенесены с `план калиток.jpg`; встроенные номера не дублируются. Предыдущий генплан сохранён в `assets/masterplan.webp` для справки. Альтернативный исходный рендер сохранён в `reference/render6-optimized.webp`. Используется оригинальный `assets/LogoPeschny.svg`. Фотографии всех шести калиток предоставлены пользователем, сохранены в assets/gate-1.jpg — gate-6.jpg и доступны офлайн.

## Обновление приложения

После изменения данных, фото или оформления:

1. Увеличьте `VERSION` в `sw.js`, например с `v8-all-gates` на `v9`.
2. Добавьте новые фотографии в список `FILES` в `sw.js`, если они должны быть доступны офлайн ещё до первого просмотра.
3. Загрузите изменённые файлы в GitHub и дождитесь публикации.
4. Откройте приложение с интернетом, затем закройте все его окна/вкладки и откройте снова. Новая офлайн-версия активируется после закрытия старой.

## Локальный просмотр

Положите папку `anapa-gates` в отдельную папку. Откройте терминал в родительской папке и выполните `python3 -m http.server 8000`. Откройте `http://localhost:8000/anapa-gates/`. Не запускайте двойным щелчком по HTML: модули и service worker требуют HTTP/HTTPS. В продакшене GitHub Pages обеспечивает HTTPS.
