# Ворота ЖК «Песчаный» — ночной план — комплект v18

Включено: новая иконка из предоставленного изображения, светлая/тёмная тема с сохранением, запуск с ворот №1, все шесть телефонов и фотографий, копирование, интерактивная карта, просмотр фото и карты на весь экран, инструкция установки и офлайн-режим.

## Загрузка на GitHub

1. Распакуйте gates-complete-v18.zip.
2. Откройте Ferrumallnight/anapa-gates → Add file → Upload files.
3. Загрузите ВСЁ содержимое архива в корень репозитория: файлы и папку assets. Не загружайте ZIP или внешнюю папку.
4. Нажмите Commit changes и дождитесь успешной публикации в Actions.
5. Откройте https://ferrumallnight.github.io/anapa-gates/ с интернетом. Дайте новой версии загрузиться, закройте все окна сайта и приложения, затем откройте снова.

Если видна прежняя версия, используйте https://ferrumallnight.github.io/anapa-gates/repair.html → «Обновить и открыть». Эта страница сбрасывает только офлайн-кеш приложения, не настройки темы. Старые файлы в репозитории можно оставить. Старые архивы поверх нового не загружайте.

## Иконка на iPhone

Новая иконка берётся из assets/icon-v16-180.png при добавлении сайта на экран Домой. Если уже установленное приложение показывает старую иконку, удалите его старый ярлык, откройте обновлённый сайт в Safari и добавьте снова: «Поделиться» → «На экран Домой» → «Добавить». После повторного добавления при необходимости включите тёмную тему ещё раз.

Изображение не перерисовывалось: сохранён присланный квадратный кадр, подготовлены размеры 180, 192 и 512 пикселей. Скругления применяет система. Manifest и Apple touch icon используют новые имена файлов, чтобы не подхватывать прежние иконки.

## Тема

По умолчанию светлая. Тумблер над заголовком сохраняет выбор на этом устройстве в localStorage (anapa-gates-theme). Обычное закрытие и перезапуск не сбрасывают его; очистка данных сайта и ограничения приватного режима могут сбросить. Между устройствами настройка не синхронизируется. После новой загрузки страницы выбраны ворота №1; смена темы не сбрасывает текущую калитку.

## Файлы релиза

index.html, styles-v18.css, app-v18.js, gates-v18.js, theme-v18.js, manifest-v18.webmanifest, sw.js, repair.html и assets/. Все данные калиток — в gates-v18.js. Версия кеша — v18-help-dialog. Для последующих изменений создавайте согласованный новый комплект и обновляйте HTML, manifest и список кеша. Не смешивайте файлы разных версий.

Базовый путь — /anapa-gates/. Для локального просмотра папка проекта должна называться anapa-gates: запустите python3 -m http.server 8000 в её родительской папке и откройте http://localhost:8000/anapa-gates/.

## Дневной и ночной план

В светлой теме показан исходный дневной план, в тёмной — предоставленный ночной план assets/masterplan-night-v17.jpg. Ночной файл сохранён без изменений. Оба изображения имеют размер 2400×1320 и используют общие маркеры, масштаб и положение. Переход карты и цветов занимает 420 мс, без задержки перед переключением. При системной настройке уменьшения движения переход отключён. Оба плана доступны офлайн после успешной первой загрузки.

## Инструкция установки

Отступ перед блоком инструкции увеличен до 36 px. Крестик нарисован симметричным SVG и центрирован в круге. При открытии фокус устанавливается на заголовок без обводки; при навигации клавиатурой кнопка закрытия сохраняет видимое выделение.
