# Ворота ЖК «Песчаный» — полный восстановительный релиз v14

Инструкция загрузки и восстановления находится в UPDATE-REPAIR.md. Адрес сайта: https://ferrumallnight.github.io/anapa-gates/.

В архив включён весь работающий комплект с последними правками: светлый дизайн, системный шрифт, иерархия заголовков, лёгкий текст, карта с белыми подписями, капсула переключения, квадратный значок копирования, отсутствие трубок, просмотр карты и фотографий на весь экран, офлайн-режим.

Телефоны и координаты не изменены. Используемая конфигурация: gates-v14.js. Для этой версии изменять данные нужно в нём, а также в исходном gates.js, затем увеличивать версию кеша sw.js. Для последующих выпусков рекомендуется новый согласованный номер файлов JS/CSS.

Все ресурсы локальные; внешние библиотеки и шрифты не нужны. Оптимизированные фотографии в assets/gate-1.webp — gate-6.webp. Base path manifest — /anapa-gates/.

Локальный просмотр: папка anapa-gates внутри родительской папки; из родительской папки python3 -m http.server 8000; адрес http://localhost:8000/anapa-gates/.

Результаты проверки — VERIFICATION.md.
