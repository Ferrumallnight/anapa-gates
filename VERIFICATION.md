# Проверка — 20 октября 2026

Локальный адрес: http://127.0.0.1:8765/anapa-gates/ . Проверено автоматизированно в установленном Chrome, с отдельным временным профилем.

Успешно:
- Страница и ресурсы доступны по вложенному пути /anapa-gates/.
- Шесть маркеров и шесть элементов списка; выбор каждого обновляет карточку.
- Калитки 2 и 3 содержат точные tel-ссылки; у 1, 4, 5, 6 кнопки отключены.
- Масштабирование кнопкой, сброс, жест двумя пальцами и перетаскивание.
- Полное отображение генплана при сбросе на ширине 320, 768 и 1280 пикселей; горизонтального переполнения страницы нет.
- Диалог инструкции установки открывается и закрывается.
- Service worker регистрируется; после первой загрузки страница и оригинальная карта повторно загружаются с отключённой сетью.
- Ошибок выполнения JavaScript не обнаружено.
- Визуально просмотрены мобильный и настольный скриншоты.
- Исходный генплан используется без перерисовки: поворот сделан стилями. Координаты перенесены из приложенной схемы.

Не проверено на физическом устройстве: системное подтверждение iOS, фактический звонок, открытие калитки, установка PWA в Safari/Android. Звонки при тестировании не совершались. Публикация в GitHub из этой сессии не выполнялась.
