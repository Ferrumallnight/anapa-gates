# Восстановление приложения

1. Распакуйте anapa-gates-complete-repair.zip.
2. В репозитории anapa-gates выберите Add file → Upload files.
3. Загрузите ВСЁ содержимое архива в корень: файлы и папку assets. Не загружайте ZIP или внешнюю папку. Подтвердите Commit changes.
4. Дождитесь успешной публикации в Actions.
5. На iPhone откройте https://ferrumallnight.github.io/anapa-gates/repair.html и нажмите «Обновить и открыть».
6. После загрузки проверьте карту с белыми плашками, переключатель-капсулу и кнопку звонка без трубки. Закройте ранее открытые окна приложения и откройте иконку на главном экране заново.

Страница восстановления сначала проверяет наличие новой версии и фото, затем удаляет только service worker области /anapa-gates/ и кеши с префиксом anapa-gates-. Файлы репозитория и данные других сайтов не удаляются. При раздельном хранилище Safari и установленного PWA откройте восстановление в том же режиме, где осталась старая версия; обычно достаточно закрыть все старые окна и снова открыть приложение после обновления сайта.

Все текущие исправления включены. Предыдущие маленькие архивы поверх этого загружать не нужно. Старые файлы в репозитории удалять не обязательно.

Эта версия загружает styles-v14.css, app-v14.js и gates-v14.js. Именно gates-v14.js содержит используемые телефоны и координаты; одноимённые файлы без v14 сохранены как исходники для дальнейшей разработки. При следующем релизе следует создать новый согласованный набор файлов с новым номером и обновить ссылки index.html и список кеша sw.js. Нельзя обновлять только HTML между разными дизайнами.
